# Go-তে Goroutines (গোরুটিনস) একদম বিস্তারিত 🚀

Go-তে সবচেয়ে শক্তিশালী ফিচারগুলোর মধ্যে একটি হলো **Goroutine**। সহজ কথায়, Goroutine হলো একটি লাইটওয়েট থ্রেড (Lightweight Thread), যা Go রানটাইম দ্বারা পরিচালিত হয়। 

এর মাধ্যমে আমরা একসাথে অনেকগুলো কাজ (Concurrent execution) করতে পারি।

---

## 📦 Goroutine কেন দরকার? (Use Case)

সাধারণত একটি প্রোগ্রামের কোড লাইন-বাই-লাইন (Synchronous) এক্সিকিউট হয়। অর্থাৎ, এক লাইনের কাজ শেষ না হওয়া পর্যন্ত অন্য লাইনে যায় না। কিন্তু বাস্তবে কিছু কাজ একসাথে হওয়া প্রয়োজন, যেমন:
- **ওয়েব সার্ভার:** একই সময়ে হাজার হাজার ইউজারের রিকোয়েস্ট হ্যান্ডেল করা।
- **ডেটা প্রসেসিং:** অনেক বড় ফাইলের ডেটা একসাথে প্রসেস করা।
- **এপিআই কল (API Calls):** বিভিন্ন জায়গা থেকে ডেটা আনার জন্য একসাথে অনেকগুলো এপিআই রিকোয়েস্ট পাঠানো।

**Goroutine** ব্যবহার করলে এই কাজগুলো একসাথে ব্যাকগ্রাউন্ডে চলতে থাকে, যার ফলে প্রোগ্রাম অনেক ফাস্ট হয়।

## 💻 `Goroutines.go` এর বিস্তারিত ব্যাখ্যা

নিচে `Goroutines.go` ফাইলের সম্পূর্ণ কোড লাইন-বাই-লাইন ব্যাখ্যাসহ দেওয়া হলো:

```go
package main

import (
	"fmt"
	"time" // সময় বা Sleep রিলেটেড কাজের জন্য এই প্যাকেজ ব্যবহার হয়
)

// ==========================================
// ১. সাধারণ ফাংশন তৈরি
// ==========================================

func task(id int) {
	fmt.Println("doing task", id)
}

func job(ids int) {
	fmt.Println("doing job ", ids)
}

// ==========================================
// ২. মেইন ফাংশন (প্রধান গোরুটিন)
// ==========================================

func main() {
	// a. সাধারণ ফাংশনকে Goroutine হিসেবে চালানো:
	// এখানে লুপ ১ থেকে ১০ পর্যন্ত চলবে। 'go' কি-ওয়ার্ড ব্যবহারের কারণে 
	// task() ফাংশনগুলো সিরিয়ালি রান না হয়ে, একসাথে (Concurrently) রান হবে।
	for i := 1; i <= 10; i++ {
		go task(i) 
	}

	// b. Anonymous (নামবিহীন) ফাংশনকে Goroutine হিসেবে চালানো:
	// এখানে লুপ ৩০ থেকে ৪০ পর্যন্ত চলবে। একটি ফাংশন ডিক্লেয়ার করেই সাথে সাথে 'go' দিয়ে চালানো হচ্ছে।
	for i := 30; i <= 40; i++ {
		go func(ids int) {
			fmt.Println("doing job", ids)
		}(i) // ফাংশনটিতে 'i' এর ভ্যালু ইনপুট (Argument) হিসেবে পাস করা হচ্ছে
	}

	// c. মেইন গোরুটিনকে থামিয়ে রাখা:
	// Go-তে main() ফাংশন নিজেই একটি Goroutine। 
	// সমস্যা হলো, মেইন ফাংশন তার কাজ শেষ করার সাথে সাথেই প্রোগ্রাম বন্ধ করে দেয়।
	// অন্যান্য Goroutine-গুলো তাদের কাজ শেষ করার সময় পায় না। 
	// তাই, time.Sleep() দিয়ে মেইন ফাংশনকে ২ সেকেন্ডের জন্য থামিয়ে রাখা হয়েছে, 
	// যেন ব্যাকগ্রাউন্ডের Goroutine-গুলো তাদের প্রিন্ট করার কাজটি শেষ করতে পারে।
	time.Sleep(time.Second * 2)
}
```

### 🖥️ কোডের ইনপুট এবং আউটপুট:

এই কোডে আমরা লুপের মাধ্যমে ইনপুট হিসেবে `1-10` এবং `30-40` এর সংখ্যাগুলো পাঠিয়েছি।

আপনি যদি `go run Goroutines.go` লিখে রান করেন, তাহলে আউটপুট **প্রতিবার আলাদা** আসবে। কারণ, Goroutine গুলো একসাথে চলতে থাকে। কে আগে প্রিন্ট করবে তার কোনো গ্যারান্টি নেই (এটি নির্ভর করে আপনার কম্পিউটারের প্রসেসরের শিডিউলারের উপর)।

**সম্ভাব্য আউটপুট:**
```text
doing task 10
doing task 1
doing job 31
doing task 2
doing task 3
doing task 4
doing job 30
... (এলোমেলোভাবে প্রিন্ট হতে থাকবে)
```

## 🧐 কিভাবে এটি কাজ করে?

১. **`go` কি-ওয়ার্ড:** যেকোনো ফাংশন কল করার আগে শুধু `go` লিখে দিলেই সেটি একটি নতুন Goroutine তৈরি করে ব্যাকগ্রাউন্ডে কাজ করা শুরু করে।
২. **নন-ব্লকিং (Non-blocking):** `go` কি-ওয়ার্ড দিলে প্রোগ্রাম ওই ফাংশন শেষ হওয়ার জন্য অপেক্ষা করে না, বরং সাথে সাথে পরের লাইনে চলে যায়।
৩. **Wait Mechanism:** উপরের কোডে আমরা Goroutine শেষ হওয়ার জন্য `time.Sleep()` ব্যবহার করেছি। তবে প্রফেশনাল লেভেলে (রিয়েল ওয়ার্ল্ড প্রজেক্টে) `Sleep` ব্যবহার করা হয় না। সেখানে **WaitGroups** বা **Channels** ব্যবহার করা হয়, যেন সব কাজ সঠিকভাবে ট্র্যাক করা যায়।
