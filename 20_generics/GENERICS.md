# Go-তে Generics (জেনেরিক্স) একদম সহজ ভাষায় 🚀

Go ১.১৮ ভার্সনে **Generics** নিয়ে আসা হয়। Generics মূলত আপনাকে এমন ফাংশন বা ডেটা স্ট্রাকচার (যেমন Struct) লিখতে সাহায্য করে, যা যেকোনো ডেটা টাইপ (যেমন- int, string, float) এর সাথে কাজ করতে পারে। 

আগে একই কাজের জন্য ভিন্ন ভিন্ন টাইপের ডেটার ক্ষেত্রে আলাদা আলাদা ফাংশন বা স্ট্রাকচার লিখতে হতো। Generics সেই কষ্ট দূর করে দিয়েছে!

---

## 📦 Generics কেন দরকার?

ধরুন, আপনি একটি ফাংশন লিখবেন যা একটি স্লাইস (Slice) এর সবগুলো আইটেম প্রিন্ট করবে। 
Generics না থাকলে আপনাকে `int` এর জন্য একটি এবং `string` এর জন্য আরেকটি ফাংশন লিখতে হতো:

```go
func printIntSlice(item []int) { ... }
func printStringSlice(item []string) { ... }
```

কিন্তু Generics থাকলে আপনি **একটি মাত্র ফাংশন** বা **একটি মাত্র Struct** লিখেই একাধিক টাইপের কাজ করতে পারবেন।

## 💻 `generics.go` এর সম্পূর্ণ কোড 

নিচে `generics.go` ফাইলের সম্পূর্ণ কোড লাইন-বাই-লাইন ব্যাখ্যাসহ দেওয়া হলো:

```go
package main

import "fmt"

// ==========================================
// ১. Generic ফাংশন তৈরি করা (নির্দিষ্ট টাইপ দিয়ে)
// ==========================================

// এখানে [T int | string] হলো Generic টাইপ প্যারামিটার। 
// এর মানে হলো: এই ফাংশনটিতে 'T' এর জায়গায় আপনি শুধুমাত্র int অথবা string পাঠাতে পারবেন।
func printSlice[T int | string](item []T) {
	for _, v := range item {
		fmt.Println(v)
	}
}

// ==========================================
// ২. 'comparable' ব্যবহার করে Generic ফাংশন
// ==========================================

// 'comparable' হলো Go-এর একটি বিল্ট-ইন ইন্টারফেস। 
// যেসব ডেটা টাইপকে '==' বা '!=' দিয়ে তুলনা করা যায় (যেমন- int, string, float64, boolean), 
// তারা সবাই comparable-এর ভেতরে পড়ে।
func printSlices[T comparable](item []T) {
	for _, v := range item {
		fmt.Println(v)
	}
}

// ==========================================
// ৩. Generic Struct তৈরি করা
// ==========================================

// আমরা একটি Generic Struct বানাচ্ছি, যা int অথবা string এর স্লাইস রাখতে পারবে।
type stack[T string | int] struct {
	element []T
}

// ==========================================
// ৪. মেইন ফাংশন
// ==========================================

func main() {
	// ----------------------------------------
	// Generic Struct ব্যবহার
	// ----------------------------------------
	
	// int টাইপের একটি stack বানালাম
	myStack := stack[int]{
		element: []int{1, 2, 3, 4},
	}
	
	// string টাইপের আরেকটি stack বানালাম
	myLange := stack[string]{
		element: []string{"go lang", "js", "c++"},
	}

	fmt.Println(myStack.element)
	fmt.Println(myLange.element)

	// ----------------------------------------
	// Generic ফাংশন ব্যবহার
	// ----------------------------------------

	name := []string{"go lang", "js", "c++"}
	
	// printSlice ফাংশনটি int এবং string সাপোর্ট করে
	printSlice([]int{1, 2, 3}) 
	printSlice(name)           

	// printSlices ফাংশনটি 'comparable' সাপোর্ট করে, তাই আমরা এখানে float64 পাঠাচ্ছি
	fmt.Println("--- Using comparable ---")
	printSlices([]float64{3.14, 2.71})
}
```

### 🖥️ কোডের আউটপুট:
এই কোডটি `go run generics.go` লিখে রান করলে টার্মিনালে নিচের রেজাল্ট আসবে:

```text
[1 2 3 4]
[go lang js c++]
1
2
3
go lang
js
c++
--- Using comparable ---
3.14
2.71
```

## 🧐 Go-তে Generics ব্যবহারের সুবিধা কী?

১. **কোড ডুপ্লিকেশন কমে যায় (DRY Principle):** 
একই লজিকের ফাংশন বা Struct বারবার আলাদা আলাদা টাইপের জন্য লেখার দরকার হয় না। 

২. **টাইপ সেফটি (Type Safety):** 
Generic ফাংশনে আপনি আগেই বলে দিতে পারেন কোন কোন টাইপ অ্যালাউড (`int | string`)। এর বাইরে অন্য কোনো টাইপ পাঠালে কম্পাইলার এরর দেবে।

৩. **`comparable` এবং `any` কি-ওয়ার্ড:**
- **`any`**: যদি আপনি চান আপনার ফাংশনটি পৃথিবীর যেকোনো টাইপ রিসিভ করুক, তাহলে আপনি `[T any]` ব্যবহার করতে পারেন।
- **`comparable`**: যখন আপনার এমন ডেটা দরকার যা শুধু ভ্যালু কম্পেয়ার (তুলনা) করতে পারবে (যেমন ম্যাপের "Key" হিসেবে), তখন `comparable` ব্যবহার করতে পারেন।
