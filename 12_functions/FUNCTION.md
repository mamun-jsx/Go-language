# Go-তে Functions (ফাংশন)

Go প্রোগ্রামে ফাংশন হলো কিছু কোডের ব্লক যা একটি নির্দিষ্ট কাজ সম্পন্ন করে। আমরা চাইলে ফাংশনের ভেতরে ডেটা (parameters) পাঠাতে পারি এবং কাজ শেষে ফাংশন থেকে রেজাল্ট (return value) পেতে পারি।

## Function এর সাধারণ Syntax

Go-তে ফাংশন ডিক্লেয়ার করার জন্য `func` কিওয়ার্ড ব্যবহার করা হয়।

```go
func functionName(parameter1 type, parameter2 type) returnType {
    // কোড এখানে থাকবে
    return result
}
```

উদাহরণ:
```go
func add(a int, b int) int {
	return a + b
}
```

## Go-তে Function এর বিভিন্ন Syntax (ধরণ)

Go-তে ফাংশন বিভিন্ন ভাবে লেখা যায়:

### ১. একই টাইপের একাধিক প্যারামিটার
যদি ফাংশনের একাধিক প্যারামিটারের ডেটা টাইপ একই হয়, তবে শেষেরটিতে টাইপ লিখলেই হয়।
```go
func mul(c, d int) int {
	return c * d
}
```

### ২. একাধিক ভ্যালু রিটার্ন করা (Multiple Return Values)
Go-এর একটি দারুণ ফিচার হলো, একটি ফাংশন থেকে একসাথে অনেকগুলো ভ্যালু রিটার্ন করা যায়।
```go
func getMultipleData() (string, int, bool) {
	return "Golang", 43, true
}
```

### ৩. Named Return Values
রিটার্ন ভ্যালুর নাম আমরা আগেই বলে দিতে পারি, সেক্ষেত্রে শুধু `return` লিখলেই হয়।
```go
func calculate(a, b int) (sum int, diff int) {
    sum = a + b
    diff = a - b
    return
}
```

### ৪. Variadic Functions (অনির্দিষ্ট সংখ্যক আর্গুমেন্ট)
যখন আমরা জানি না কয়টি আর্গুমেন্ট আসবে, তখন `...` ব্যবহার করা হয়।
```go
func sumAll(nums ...int) int {
    total := 0
    for _, num := range nums {
        total += num
    }
    return total
}
```

## First-Class Functions: একটি ফাংশনকে অন্য ফাংশনে পাস করা (Line 25)

Go-তে ফাংশনকে **First-class citizen** বলা হয়। এর মানে হলো, আপনি একটি ভেরিয়েবলের মধ্যে ফাংশন রাখতে পারবেন, অথবা একটি ফাংশনকে অন্য একটি ফাংশনের আর্গুমেন্ট (প্যারামিটার) হিসেবে পাঠাতে পারবেন। একে বলা হয় **Higher-Order Function**।

আপনার ফাইলের ২৫ নাম্বার লাইনের কোডটি লক্ষ্য করুন:

```go
// ২৫ নম্বর লাইনের ফাংশন: 
func processIt(fn func(k int) int) {
	fn(2)
}
```

**এখানে যা ঘটছে:**
- `processIt` হলো একটি ফাংশন, যা প্যারামিটার হিসেবে `fn` নামের আরেকটি ফাংশন গ্রহণ করে।
- সেই `fn` ফাংশনটির নিয়ম (signature) হলো: এটি একটি `int` টাইপের ভ্যালু ইনপুট হিসেবে নিবে এবং একটি `int` টাইপের ভ্যালু রিটার্ন করবে (`func(k int) int`)।
- `processIt` এর ভেতরে আমরা `fn(2)` কল করেছি, অর্থাৎ যেই ফাংশনটি আর্গুমেন্ট হিসেবে আসবে, তাকে `2` দিয়ে কল করে দেওয়া হয়েছে।

**এটি কিভাবে কাজ করছে (`main` ফাংশনের ভেতরে):**

```go
func main() {
    // একটি ফাংশন তৈরি করে fn ভেরিয়েবলে রাখা হলো
	fn := func(v int) int {
		return 9
	}

    // processIt-কে কল করা হলো এবং fn-কে আর্গুমেন্ট হিসেবে পাঠানো হলো
	processIt(fn)
}
```
১. প্রথমে আপনি `fn` নামে একটি Anonymous (নামহীন) ফাংশন তৈরি করেছেন যা সবসময় `9` রিটার্ন করে।
২. তারপর আপনি `processIt(fn)` কল করে সেই ফাংশনটি পাস করে দিয়েছেন।
৩. `processIt` এর ভেতরে গিয়ে আপনার পাঠানো ফাংশনটি `2` ইনপুট নিয়ে রান হবে।

এই ধরনের টেকনিক কলব্যাক (callbacks) বা কাস্টম লজিক পাস করার জন্য খুবই কাজে লাগে।
