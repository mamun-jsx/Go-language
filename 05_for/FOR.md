# For Loop (ফর লুপ) - Go Language

Go-তে লুপ করার জন্য শুধুমাত্র একটি উপায় আছে, আর তা হলো `for` লুপ। অন্য ল্যাঙ্গুয়েজগুলোর মতো এখানে `while` বা `do-while` লুপ নেই, `for` দিয়েই সব কাজ করা যায়।

### লুপ কেন লাগে?
যখন কোনো কাজ আমাদের বারবার করতে হয়, তখন লুপ ব্যবহার করা হয়। যেমন: ১ থেকে ১০ পর্যন্ত প্রিন্ট করা।

### সাধারণ For Loop:
```go
package main

import "fmt"

func main() {
    // 1 থেকে 5 পর্যন্ত প্রিন্ট করা
    for i := 1; i <= 5; i++ {
        fmt.Println("নম্বর:", i)
    }
}
```

### While Loop এর মতো ব্যবহার:
আমরা চাইলে `for` কে অনেকটা while লুপের মতো করেও লিখতে পারি। শুধু কন্ডিশনটা দিলেই হবে।
```go
package main

import "fmt"

func main() {
    i := 1
    for i <= 3 {
        fmt.Println("ভ্যালু:", i)
        i = i + 1
    }
}
```

### অসীম (Infinite) লুপ:
লুপ যদি অনন্তকাল ধরে চলতে থাকে। এটি ব্রেক করার জন্য `break` ব্যবহার করতে হয়।
```go
package main

import "fmt"

func main() {
    for {
        fmt.Println("লুপ চলছে...")
        break // লুপটি একবারে মেনেই থামিয়ে দিলাম
    }
}
```
