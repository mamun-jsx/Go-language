# Variables (ভ্যারিয়েবল) - Go Language

**ভ্যারিয়েবল** হলো ডাটা বা ভ্যালু রাখার একটি পাত্র (Container)। যখন আমরা কোনো তথ্য কম্পিউটারের মেমরিতে রাখতে চাই, তখন আমরা একটি ভ্যারিয়েবল তৈরি করি এবং তার একটি নাম দিই।

Go-তে ভ্যারিয়েবল ডিক্লেয়ার করার দুইটি মূল উপায় আছে।

### ১. `var` কি-ওয়ার্ড ব্যবহার করে:
এই উপায়ে আমরা স্পষ্টভাবে বলে দিই যে এটি কী ধরণের ভ্যারিয়েবল (যেমন int, string)।

```go
package main

import "fmt"

func main() {
    // String ভ্যারিয়েবল
    var name string = "Mamun"
    fmt.Println("আমার নাম:", name)

    // Integer (সংখ্যা) ভ্যারিয়েবল
    var age int = 25
    fmt.Println("আমার বয়স:", age)

    // Go নিজে থেকেই ডাটা টাইপ বুঝে নিতে পারে
    var country = "Bangladesh" 
    fmt.Println("আমার দেশ:", country)

    // একসাথে একাধিক ভ্যারিয়েবল ডিক্লেয়ার করা
    var b, c int = 1, 2
    fmt.Println(b, c)
}
```

### ২. শর্টহ্যান্ড ডিক্লেয়ারেশন (`:=`):
Go-তে খুব সহজে ও দ্রুত ভ্যারিয়েবল তৈরি করার জন্য `:=` ব্যবহার করা হয়। এর জন্য `var` লেখার প্রয়োজন হয় না। 

> **বিঃদ্রঃ** এটি শুধুমাত্র ফাংশনের ভেতরে ব্যবহার করা যায়।

```go
package main

import "fmt"

func main() {
    // var এর বদলে := ব্যবহার
    city := "Dhaka"
    fmt.Println("আমার শহর:", city)

    year := 2026
    fmt.Println("বর্তমান সাল:", year)
}
```

### কেন ভ্যারিয়েবল দরকার?
কোনো মান বা ডাটাকে বারবার ব্যবহার করার জন্য বা পরিবর্তন করার জন্য আমরা ভ্যারিয়েবল ব্যবহার করি।
