# Variadic Functions (ভ্যারিয়াডিক ফাংশন)

Go-তে **Variadic Function** হলো এমন একটি ফাংশন যা অনির্দিষ্ট সংখ্যক (যেকোনো সংখ্যক) আর্গুমেন্ট গ্রহণ করতে পারে। 

JavaScript-এ আমরা যেমন **Rest (...)** অপারেটর ব্যবহার করে একাধিক ডাটা একসাথে রিসিভ করি, এটি ঠিক সেভাবেই কাজ করে।

## উদাহরণ

আপনার কোডটিতে লক্ষ্য করুন:

```go
func sum(numbs ...int) int {
	total := 0
	for _, num := range numbs {
		total = total + num
	}
	return total
}
```

এখানে `sum` ফাংশনের প্যারামিটার হলো `numbs ...int`। 
- **`...int` এর মানে:** ফাংশনটি কল করার সময় আপনি চাইলে ১টি, ২টি, ৩টি বা তার বেশি যত খুশি `int` ভ্যালু পাঠাতে পারবেন (যেমন: `sum(1, 2, 3)`)। 
- Go এই সবগুলো ভ্যালুকে একসাথে করে একটি **Slice** (এক্ষেত্রে `[]int`) হিসেবে `numbs`-এর ভেতরে রেখে দেয়। 

---

## `...` এর ব্যবহার: Parameter (Rest) বনাম Argument (Spread)

Go-তে `...` এর ব্যবহার কোথায় হচ্ছে তার ওপর ভিত্তি করে এর কাজ ভিন্ন হয়। এটি JavaScript এর **Rest** এবং **Spread** অপারেটরের সাথে পুরোপুরি মিলে যায়।

### ১. প্যারামিটার ডিক্লেয়ার করার সময় (Rest-এর মতো)
যখন ফাংশন তৈরি করার সময় `...` ব্যবহার করা হয়, তখন এটি অনেকগুলো আর্গুমেন্টকে একত্রে একটি স্লাইস (Slice) বানায়।

**কোথায় বসে:** টাইপের নামের ঠিক আগে (যেমন: `...int`, `...string`)।
```go
// এখানে ...int অনেকগুলো সংখ্যাকে গ্রহণ করে numbs স্লাইস বানাবে
func sum(numbs ...int) {
    // ...
}
```

### ২. আর্গুমেন্ট পাঠানোর সময় (Spread-এর মতো)
আপনার কাছে যদি আগে থেকেই একটি Slice থাকে (যেমন `numberss := []int{1, 2, 3}`), এবং আপনি সেটি Variadic ফাংশনে পাঠাতে চান, তখন আপনাকে Slice-এর নামের শেষে `...` ব্যবহার করতে হবে। এটি Slice-এর ভেতরের ভ্যালুগুলোকে আলাদা আলাদা (spread) করে ফাংশনে পাঠায়।

**কোথায় বসে:** ভেরিয়েবলের নামের শেষে (যেমন: `numberss...`)।
```go
numberss := []int{1, 2, 3, 4, 5}

// এখানে numberss... স্লাইসটিকে ভেঙে আলাদা আলাদা ভ্যালু হিসেবে ফাংশনে পাঠাচ্ছে
sum(numberss...) 
```

**সংক্ষিপ্ত সারমর্ম:**
- `func sum(numbs ...int)` ➔ **Rest:** অনেকগুলো ভ্যালুকে জোড়া লাগিয়ে Slice বানায়।
- `sum(numberss...)` ➔ **Spread:** একটি Slice-কে ভেঙে আলাদা আলাদা ভ্যালুতে পরিণত করে।
