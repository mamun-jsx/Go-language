# Go-তে Interface (ইন্টারফেস) একদম সহজ ভাষায় 🚀

ইন্টারফেস জিনিসটা শুরুতে বুঝতে একটু কঠিন লাগতে পারে, কারণ এটি কোনো বস্তু নয়, এটি একটি **ধারণা বা নিয়ম**। 

## 📦 বাস্তব জীবনের একটি উদাহরণ দিয়ে বুঝি
ধরুন, একটি কোম্পানির বস বলছেন: *"আমার কোম্পানিতে তাকেই চাকরি দেওয়া হবে, যে 'টাইপ' (Type) করতে পারে।"*

এখানে বস কিন্তু বলেননি যে মানুষ হতে হবে, নাকি রোবট হতে হবে, নাকি এলিয়েন হতে হবে! বসের একমাত্র শর্ত হলো **টাইপ করতে পারা**। 

- যদি একজন মানুষ এসে টাইপ করে দেখায়, সে চাকরি পাবে।
- যদি একটি রোবট এসে টাইপ করে দেখায়, সে-ও চাকরি পাবে।

এই যে বসের **"শর্ত বা কাজের তালিকা"**, এটাই হলো **Interface**।
আর মানুষ বা রোবট, যারা এই কাজগুলো করে দেখায়, তারা হলো **Struct**।

---

## 💻 `Student` এর উদাহরণ দিয়ে সম্পূর্ণ কোড 

আমরা এখন একটি `Learner` (শিক্ষার্থী) ইন্টারফেস বানাব। শর্ত হলো: যার ভেতরে `Study()` (পড়াশোনা করার) মেথড আছে, সে-ই একজন `Learner`। সে স্কুলের ছাত্র হোক বা কলেজের ছাত্র হোক, তাতে কিছু যায় আসে না।

নিচে `interface.go` ফাইলের সম্পূর্ণ কোড লাইন-বাই-লাইন ব্যাখ্যাসহ দেওয়া হলো:

```go
package main // এটি main প্যাকেজ, যা থেকে প্রোগ্রাম রান করা শুরু হয়

import "fmt" // আউটপুট দেখানোর জন্য 'fmt' প্যাকেজ ইমপোর্ট করা হলো

// ==========================================
// ১. ইন্টারফেস তৈরি করা (বসের শর্ত)
// ==========================================

// 'Learner' নামের একটি ইন্টারফেস বানাচ্ছি। 
// শর্ত: যার ভেতরে 'Study()' নামের একটি ফাংশন/মেথড থাকবে যা string রিটার্ন করে, সে-ই Learner।
type Learner interface {
	Study() string 
}

// ==========================================
// ২. আলাদা আলাদা Struct (ডেটা রাখার বাক্স) তৈরি
// ==========================================

// 'SchoolStudent' নামের একটি Struct বানালাম, যার ভেতরে শুধু Name আছে
type SchoolStudent struct {
	Name string
}

// 'CollegeStudent' নামের আরেকটি Struct বানালাম, এর ভেতরেও শুধু Name আছে
type CollegeStudent struct {
	Name string
}

// ==========================================
// ৩. শর্ত পূরণ করা (Struct-গুলোর জন্য Study মেথড লেখা)
// ==========================================

// SchoolStudent এর জন্য Study() মেথড লিখছি। 
// যেহেতু এর ভেতরে Study() মেথড আছে, তাই Go অটোমেটিক বুঝে নেবে যে SchoolStudent একজন Learner।
func (s SchoolStudent) Study() string {
	return s.Name + " স্কুলের বই মুখস্থ করছে।"
}

// একইভাবে CollegeStudent এর জন্যও Study() মেথড লিখছি।
// সে-ও এখন থেকে একজন Learner হিসেবে গণ্য হবে।
func (c CollegeStudent) Study() string {
	return c.Name + " কলেজের প্রজেক্ট নিয়ে গবেষণা করছে।"
}

// ==========================================
// ৪. ম্যাজিক ফাংশন (যে ইন্টারফেস ব্যবহার করে)
// ==========================================

// StartLearning নামের একটি ফাংশন বানালাম, যা ইনপুট হিসেবে 'Learner' নেয়। 
// এখানে খেয়াল করুন, আমরা SchoolStudent বা CollegeStudent বলিনি। 
// এর মানে হলো, যে কেউই যদি Learner-এর শর্ত পূরণ করে, সে এই ফাংশনের ভেতরে ঢুকতে পারবে।
func StartLearning(l Learner) {
	// সে জানে 'l' যেই হোক না কেন, তার ভেতরে Study() মেথড আছেই। তাই সে কল করে দিল।
	fmt.Println(l.Study())
}

// ==========================================
// ৫. মেইন ফাংশন (যেখান থেকে প্রোগ্রাম শুরু হয়)
// ==========================================

func main() {
	// SchoolStudent এর একটি অবজেক্ট/ইনস্ট্যান্স তৈরি করলাম, যার নাম "রহিম"
	schoolBoy := SchoolStudent{Name: "রহিম"}
	
	// CollegeStudent এর একটি ইনস্ট্যান্স তৈরি করলাম, যার নাম "করিম"
	collegeBoy := CollegeStudent{Name: "করিম"}

	// রহিম (SchoolStudent) কে StartLearning ফাংশনে পাঠালাম। 
	// সে Learner এর শর্ত পূরণ করেছে বলে কোনো Error আসবে না।
	StartLearning(schoolBoy)
	
	// করিম (CollegeStudent) কেও একই ফাংশনে পাঠালাম। 
	StartLearning(collegeBoy)
}
```

### 🖥️ কোডের আউটপুট:
এই কোডটি `go run interface.go` লিখে রান করলে টার্মিনালে নিচের রেজাল্ট আসবে:

```text
রহিম স্কুলের বই মুখস্থ করছে।
করিম কলেজের প্রজেক্ট নিয়ে গবেষণা করছে।
```

## 🧐 কেন আমরা Interface ব্যবহার করি? (আসল সুবিধা)

উপরের কোডে `StartLearning(l Learner)` ফাংশনটির দিকে আবার তাকান। 

ধরুন, কালকে আপনি `UniversityStudent` নামে নতুন আরেকটি Struct বানালেন। 

**Interface না থাকলে কী হতো?**
আপনাকে `StartLearningForSchool`, `StartLearningForCollege`, `StartLearningForUniversity`—এভাবে আলাদা আলাদা ফাংশন লিখতে হতো। যা খুবই বিরক্তিকর।

**Interface থাকার কারণে কী লাভ হলো?**
আপনাকে শুধু `UniversityStudent` এর জন্য একটি `Study()` মেথড লিখতে হবে। আর কিচ্ছু করতে হবে না! আপনি সরাসরি `StartLearning(universityBoy)` কল করতে পারবেন। `StartLearning` ফাংশনের ভেতরে কোনো চেঞ্জ করতে হবে না, কারণ সে জানে যে সে একজন `Learner` কে পাচ্ছে, আর তার কাজ শুধু `Study()` কল করে দেওয়া।

অর্থাৎ, **কোড অনেক ডাইনামিক এবং ফ্লেক্সিবল হয়।**
