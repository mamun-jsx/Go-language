# Go (Golang) এ Closure (ক্লোজার) কী?

Closure হলো এমন একটি ফাংশন যা তার বাইরের (outer) স্কোপের ভেরিয়েবলগুলোকে অ্যাক্সেস এবং ব্যবহার করতে পারে, এমনকি বাইরের ফাংশনটির কাজ শেষ হয়ে যাওয়ার পরেও। Go-তে আমরা সাধারণত অ্যানোনিমাস ফাংশন (যে ফাংশনের কোনো নাম নেই) ব্যবহার করে Closure তৈরি করি। 

## Closure কীভাবে কাজ করে?
একটি Closure তার বাইরের স্কোপের ভেরিয়েবলগুলোকে "মনে রাখে" এবং যখনই Closure-টি কল করা হয়, সে ওই ভেরিয়েবলগুলোকে ব্যবহার করতে পারে বা পরিবর্তন করতে পারে।

## উদাহরণ বিশ্লেষণ (`closures.go` থেকে)

```go
package main

import "fmt"

func counter() func() int {
	var count int = 0
	return func() int {
		count += 1
		return count
	}
}

func main() {
	increment := counter()

	fmt.Println("increment : ", increment()) // আউটপুট: 1
	fmt.Println("increment : ", increment()) // আউটপুট: 2
	fmt.Println("increment : ", increment()) // আউটপুট: 3
}
```

### এখানে কী হচ্ছে?
১. `counter()` এমন একটি ফাংশন যা নিজে আরেকটি ফাংশনকে রিটার্ন করে (`func() int`)।
২. `counter()` এর ভেতরে `count` নামের একটি লোকাল ভেরিয়েবল আছে যার মান শুরুতে 0।
৩. রিটার্ন করা অ্যানোনিমাস ফাংশনটি (যেটা ভেতরের ফাংশন) `count` ভেরিয়েবলটিকে অ্যাক্সেস করতে পারছে এবং তার মান ১ করে বাড়াচ্ছে।
৪. `main` ফাংশনে যখন আমরা `increment := counter()` কল করি, তখন `count` এর মান 0 দিয়ে ইনিশিয়ালাইজ হয় এবং `increment` ভেরিয়েবলের মধ্যে ভেতরের অ্যানোনিমাস ফাংশনটি স্টোর হয়।
৫. এরপর যতবার আমরা `increment()` কল করি, ততবার Closure-টি তার আগের `count` এর মান মনে রাখে এবং তাকে 1 করে বাড়িয়ে রিটার্ন করে।

এর ফলে প্রথমবার কল করলে `1`, দ্বিতীয়বার কল করলে `2` এবং তৃতীয়বার কল করলে `3` আউটপুট হিসেবে পাওয়া যায়। এটিই হলো Closure-এর আসল ক্ষমতা—সে তার স্টেট (state) বা ভেরিয়েবলের অবস্থা মনে রাখতে বা ধরে রাখতে পারে!
